**R120**: the first public release (2026-10-02). Six named modes (UHD, XQ, HQ, MQ, LQ, S16), a 12 / 14-bit choice, lossless compression as a switch, gyro data in every frame, STILL native.

Superseded by R166. Sigma fp, firmware 5.02 only.

Install: unzip, copy `FPOG.BIN`, `AutoRun.txt` and `BOOT.BIN` to the root of the SD card.
